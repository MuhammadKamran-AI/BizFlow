# BizFlow Landing Page

A modern business landing page for a digital agency and consultancy brand. This project showcases a clean corporate design with a hero section, services, about section, team cards, testimonials, and contact call-to-action.

## Project Overview

This project was created as a front-end web assignment and is built using:

- HTML5
- CSS3
- Responsive design
- Static assets for branding and team photos

## Live Preview

Open the project locally in a browser:

1. Open `index.html` directly in your browser, or
2. Run a local server from the project folder:

```bash
python -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```

## How to Run

### Option 1: Open directly
- Double-click `index.html` in your file explorer, or
- Right-click and choose a browser to open it

### Option 2: Use a local server
From the project folder:

```bash
cd WEB_ASSIGN_02
python -m http.server 8000
```

Then open the site in your browser at `http://localhost:8000`.

## GitHub Upload Guide

1. Initialize a Git repository:

```bash
git init
```

2. Add all files:

```bash
git add .
```

3. Commit your project:

```bash
git commit -m "Initial commit"
```

4. Create a GitHub repository on GitHub.
5. Link the local repo to GitHub:

```bash
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/YOUR_REPOSITORY_NAME.git
```

6. Push the project:

```bash
git push -u origin main
```
